#AI数字人分身系统 v1.4.0+v1.3.8独立版 小程序端+H5端+WEB端（uniapp开源端）

源码获取：ym7k.com/18843/

这套是多端合一的 AI 数字人分身独立源码系统，双版本打包交付，uniapp 前端开源可改，覆盖小程序、H5、网页 WEB 端，主打数字人视频生成、数字人直播、分身克隆，适合短视频带货、口播宣传片、知识 IP、本地商家、AI 工作室接单变现。

## ✅ 版本说明

- v1.4.0：新版，功能迭代更多，修复旧版 BUG，新增数字人模板、音色库、字幕样式、批量导出、任务队列优化
- v1.3.8：稳定老版本，兼容性强，适合低配服务器、只做基础口播视频场景，可按需选择部署
- 前端：UniApp 开源端（源码无加密，可二次开发改 UI、改页面、增减功能，打包微信小程序 / H5）
- 后端：PHP 独立版，非 SaaS，源码私有化部署，数据自己掌控

## ✅ 三端覆盖

1. 微信小程序端：手机轻量化使用，客户自助输入文案生成数字人视频，适合 C 端用户
2. H5 端：微信内直接打开，不用上架小程序，适合引流、私域分发
3. WEB 网页端：电脑后台操作台，适合工作室批量制作、批量管理任务、导出高清视频

## ✅ 核心功能模块

1. **AI 数字人克隆分身**
支持上传照片 / 短视频，生成专属形象数字分身；2D 写实、卡通数字人形象模板库，自由切换形象、妆容、服装。
2. **AI 语音合成 TTS**
海量音色：普通话、方言、多国外语，支持情绪音色（开心、沉稳、温柔）；支持上传音频驱动数字人对口型。
3. **智能文案生成**
内置 AI 大模型接口接入，输入主题自动生成口播脚本；支持导入 TXT 文案、长文本自动断句。
4. **字幕 & 视频包装**
自动字幕生成、字幕字体 / 颜色 / 描边自定义；支持添加背景图、背景视频、logo 水印、背景音乐、片头片尾。
5. **批量任务生成**
批量导入多条文案，队列自动渲染数字人视频，适合矩阵账号批量起号。
6. **数字人直播（增值）**
部分版本附带实时驱动数字人直播，文本实时推流，直播间自动口播。
7. **用户权限 & 套餐计费**
后台配置会员套餐、次数充值、时长包；支持按生成视频分钟扣费、按条扣费；卡密充值、分销邀请裂变。
8. **作品管理**
我的数字人、我的视频、渲染任务列表、历史记录、下载管理；支持分享 H5 给客户预览。
9. **后台管理面板**
用户管理、订单充值记录、音色管理、数字人形象管理、接口密钥配置、敏感词过滤、轮播公告、数据统计看板。

## ✅ 接口依赖说明

> 
> 系统本身是调度平台，数字人渲染、语音能力需要对接第三方接口：

- 数字人服务商接口（如各类数字人 API）
-TTS 语音合成接口
- AI 文案大模型接口（GPT / 国内大模型）
可后台自由填密钥切换服务商

## ✅ 变现方式

- 按次 / 按时长售卖数字人视频生成次数，给短视频博主、商家做口播视频
- 会员包月无限额度套餐
- 给同行、工作室部署源码，售卖部署 + 搭建服务
- 数字人直播代搭建、代调试
- 企业定制：企业 IP 数字分身、展厅数字讲解员
